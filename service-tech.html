PAGE DE LOGIN SABOTÉE
Afin de vous empêcher de suivre votre formation, le hacker a bloqué la page de connexion à l'intra. Comme vous pouvez le voir, le bouton « Se connecter » a disparu. Inspectez le code HTML suivant pour le faire réapparaître.

Que chercher ?

  • Trouvez la ligne avec <button>
  • Regardez le style CSS, c'est le type de code qui définit l'apparence d'une page internet
  • Supprimez ou modifiez la propriété qui cache le bouton
  • Le bouton devrait apparaître dans l'aperçu à droite
